Drag this button to your browser’s bookmarks bar:

Capture GC plays

  1. Sign into GameChanger normally and open a game’s Plays view.
  2. Expand the innings and load the plays you want. Click the Capture GC plays bookmark while viewing GameChanger.
  3. Review the captured text, review the detected game date, start time and timezone; confirm a season-suggested year if shown, then choose Download TXT or Copy import prompt.
  4. Attach or paste that output in your Diamond-Scout conversation. Both teams are imported by default using TEAM-DATA-PROMPT.md.
First version — live page compatibility unverified.

Only currently loaded text is captured. Check both first-inning halves and the final supplied plays. GameChanger may load or unmount plays as you scroll; the helper cannot certify completeness.

If automatic detection fails, select the play text including its inning/team headings and click the bookmark again. If the browser blocks the bookmarklet, use normal copy/paste; do not change browser security settings.

This helper makes no network requests and does not read passwords, cookies or browser storage. GameChanger login remains in your browser. It does not change team JSON or the app. Source URL query strings and fragments are excluded.
