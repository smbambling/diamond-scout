Capture GC data

  1. Sign into GameChanger normally and open the intended game. Plays do not require expanding innings.
  2. Click the bookmark once. It loads Plays and Box score in a temporary visible window using the normal signed-in website. Keep the capture window open while both pages are read. Your original game stays open.
  3. Review the detected date, start time, teams, inning headings, table counts and warnings. Confirm a season-suggested year when requested.
  4. Choose Download game JSON. Import the single file: node tools/import-plays.cjs /path/gamechanger-game-2026-10-25.json. Add --write when ready, or use --preflight to review a batch.
Updated after live feedback; capture-window compatibility still needs verification.

Only loaded, rendered content is captured; waiting for the screen to settle does not prove completeness. Canvas-drawn or unrecognized tables may produce a notes-only warning. A missing first-inning half is flagged. Always check the review screen.

If the browser blocks/closes the capture window or a page times out, choose Capture current screen only, then capture Plays and Box score separately. Pair them with node tools/import-plays.cjs plays.txt --box-score boxscore.json. Cancel stops capture and closes the temporary window.

The helper uses normal game-page navigation. It does not call private APIs, access credentials/cookies/browser storage, upload data, or change team JSON. URL credentials, queries and fragments and account/navigation text are excluded from saved game data.
